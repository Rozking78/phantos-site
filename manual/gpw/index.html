Operator Manual / GPW timeline

10GPW timeline

GPW is the console's timeline: tracks, events, automation curves and a playhead that free-runs or follows the Command timecode. Open it from the workspace tile or a detached screen — both drive the same timeline.

Transport

Play free-runs the playhead; Stop pauses and returning to zero is the ⏮ button. TC follows the Command timecode (external Art-Net LTC, or the program clock). While following, the playhead is clamped to the arrangement — if the source is not arriving the readout says so and the playhead holds rather than running away. Loop wraps a region in free-run only; an external clock owns the position, so loop is inert under TC.

Scrubbing

Every scrub — the transport slider, a ruler click, the minimap — is a real seek: bound video follows, and events behind the playhead re-arm, so dragging back before a cue and rolling again fires it again. A loop wrap does the same.

Events & fades

An event fires a preset recall, an executor GO (a real cue advance, identical on every pass), an executor toggle-recall, an intensity set, or a custom command. A preset event's fade in/out belongs to that event — it rides the one recall and never changes the console's Prog Time.

Drag a block to move it. Drag either end of a block to pull a fade in or out — the grips are offered only on a block wide enough to hold them and still be draggable, so zoom in if you want them. On a short block the whole block moves and the fades are set as numbers: tap the block to open the event editor, which carries Fade In and Fade Out as fields. Long-press (or right-click) the timeline for the rest — add an event at the playhead, set the loop in/out, and, with an event selected, lock, disable, edit, duplicate or delete it.

The GPW Transport tile (Playback)

Drop a GPW Transport tile anywhere on the workspace (it takes exactly five columns). It drives the same timeline as the GPW window. Down the centre: the time readout and the arrangement name; ⏮ · play · stop · record-arm · TC · ↻ loop; and the scrub fader along the bottom. Every fader on the tile is the console's standard fader — grab-and-drag, so a mistap never snaps the playhead. Scrubbing is a real seek — bound video follows and events re-arm, exactly as in the window. The ↻ loop button arms the timeline's loop (green when armed); an empty region defaults to the whole arrangement, and loop wraps in free-run only.

Tap the arrangement name and a list pops out: pick any saved GPW arrangement to load and play it, New Arrangement to start a fresh one, or Save as GPW Preset to bank the current one — the same pool the GPW window's preset strip holds.

Flanking the transport are two full-height faders — TTE (Trans Time, the programmer fade time, exactly what fade <sec> and the Prog Fade bezel set) on the left and TTR (Trans Rate, the switcher's transition rate) across from it on the right. TTE arms the prog fade when raised off the bottom and disarms at the bottom; TTR reads in frames and reaches the switcher's mix rate — with no ATEM patched it says so where the throw would be rather than pretending to drive one.

GPW presets — save a timeline, recall it playing

The strip to the right of the transport holds numbered GPW presets. ＋ saves the current arrangement into the next free slot (loop region included), and the key beside it starts a new blank arrangement outright (bank the current one with ＋ first; it is undoable either way). Tap a preset and it loads and PLAYS from the top — recall is a GO, not just a load. Long-press (or right-click) a tile to overwrite it with the current arrangement or delete it. The green tile is the active preset; the orange dot means the current arrangement has unsaved changes.

Tracks

A track header carries its name and five keys: M mute · S solo · R record-arm · A show this track's automation lanes · the padlock. Tap the name to rename it on the keypad, and drag the coloured strip down the left edge of the header up or down to resize the track — it is the track's colour and its resize grip, a full-height handle rather than the hairline it used to be. Long-press (or right-click) the header to delete the track or add an automation lane; with lanes shown, the I P C G B keys add one directly.

Assign a video — its timelines arrive with it

Tap Assign Video in the row along the bottom of the window (Zoom · Assign Video · Events · + at playhead) and pick a slot from the list; the track's row fills in: a strip of video thumbnails along the timeline, and an audio waveform band underneath, both scaled to the zoom, with an amber dashed line at the end of the media. The arrangement takes the slot's duration. Scrub and the slot follows.

This needs the file on this Mac. Media lives on Light, so when the console cannot find a local copy the row says so in orange and draws only the slot name and duration ticks off Light's report — it will never draw a waveform it does not have. Keep the file in a media folder listed in Settings ▸ Content and the picture and waveform come back.

Keys, loops, markers, follow

With a GPW window open the timeline keys are live: Space play/pause · I/O loop in/out at the playhead · M drop a marker · ,/. previous/next marker · Tab step events · N new event · ←/→ nudge (⇧ = one frame) · J/K/L skip back/pause/skip forward · R record-arm · T TC chase · F follow · Home/End · ⌘Z/⌘⇧Z (GPW's own undo) · ⌘C/⌘V/⌘X/⌘D events · ⌘=/⌘−/⌘0 zoom. The transport bar carries touch twins for the loop (I/O), the markers (⟨ ⚑ ⟩) and follow — with follow on, the paper pages so the playhead never walks off screen. Keys stay out of text fields.

None of that needs a keyboard. Press and hold the timeline — or right-click it — and a list pops out. With an event selected it holds Lock / Unlock Position, Disable / Enable, Edit…, Duplicate and Delete; with nothing selected, Add Event at Playhead and the two loop points (and Disable Loop when the loop is armed). Dragging still does what it always did — rubber-band a selection, move an event, drag a breakpoint, seek from the ruler — because a press that moves is a drag and never opens the list.

Record-arm

Arm REC and play: preset recalls, executor GOs and executor taps land as events at the playhead; fader moves land as automation breakpoints (while rolling). The timeline never records its own playback. The R flag picks the record-target track (track 1 with none armed); M mutes a track's events and S solos.

Automation — lanes drive the rig on their own plane

A recorded lane plays back onto exactly the fixtures it was recorded on — never the current selection. Its values ride a dedicated GPW plane below your hand: a programmer write or camera move always wins over the timeline, and an executor whose priority you have raised above 104 out-holds it too — that is by design. Clear never touches timeline output (clear your programmer freely while it plays); Master Clear stops the timeline and releases its output — it is the panic button. Stop releases everything cleanly; muting a track drops just its lanes and unmuting brings them back. Record never captures the timeline's own output. A lane with no recorded fixtures shows an orange note and drives nothing. Long-press (or right-click) a lane header to promote the breakpoint at the playhead into a real preset, or to delete the lane.

Not built yet — and this page is where it says so

There is no upload from GPW: hover Assign Video and its tip sends you to the Media window instead (＋ New ▸ Upload files to Light…), and assigning an existing slot here works and scrubs. There is no playing video picture in the window, and no manual Load Audio; the thumbnail strip and waveform only appear for media the console can find on this Mac — it cannot pull a file back off Light to read it. Automation capture is fader-scoped for now (widening is planned).
