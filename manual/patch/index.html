8Patch & devices

Patching tells the desk what is out there and where it lives. Everything is patched the same way, whether it ends up as DMX, an ATEM command or a camera move.

Tap fixture cards to edit them. Live selection starts off: browsing Patch, Command-clicking, Shift-clicking, and None affect the Patch editor selection only. Turn it on to send subsequent Patch selections to the programmer too. Turning it on or off does not itself change the programmer selection.

Patching

How do I patch a fixture?
  1. Open Patch and tap Add. The Add flow takes the whole window: the fixture library on the left, the setup cards on the right. Search the library, pick manufacturer, model and mode, set the quantity, and press Add Fixture (top right or bottom). Back to patch returns to the cards without adding.
  2. Leave the address on auto and the console finds the first gap that fits. A batch spills into the next universe by itself, and the placement card shows you the plan before you commit — → U1.1 … U2.13 (12 fixtures) — or refuses in orange if there is no room.
  3. Or from the command line, when you know the profile ID: patch phantos_full 1 @1/1.

The Add flow checks addresses; the typed verb does not

patch refuses a fixture number that is already taken, but it does not check whether the DMX address overlaps something else — and with no @u/a it lands at universe 0, address 1. Use the Add flow when you want the console to find you a clean address.

CommandWhat it does
patch <profile> <num> @<uni>/<addr>Patch a fixture at a number and an address. An unknown profile ID is refused, with the list of valid ones.
unpatch 5 · unpatch allRemove it.
readdress 5 1/21Move it. This one does check for an overlap and refuses without changing anything.
renumber 5 12Change its fixture number. Refused if the number is taken, or if presets, groups, cues or pad bindings still point at it.
label fixture 5 as Spot LName it.
domain 1 thru 5 recordingSay what kind of thing these are: lighting, media, camera, sound, recording, switching, displays. domain 1 thru 5 profile hands it back to the profile.
host 10 192.168.1.50 [port]Give a network device its address. Leave the port off and the device family's own default is used — 9910 for ATEM, 80 for Panasonic, 52381 for VISCA.

The fixture's domain is what makes the per-domain clears and releases work, and what tints its tile. It normally comes from the profile; set it by hand when the profile is generic. A universe takes on the domain of whatever is patched lowest in it, and the placement card tells you when you are about to mix domains in one universe.

Reading the Patch window

Fixtures are cards, in the same language as the pool tiles: the fixture number, its name, its profile, its universe and address (1.163), its channel count, and its IP if it is a network device. Cards are grouped by universe. Each universe heading carries the domain the universe holds and a gauge of how many of its 512 channels are used, so a full universe is visible at a glance. Search and Sort work inside the groups.

Tap a card to select it — it lights green and its editor opens beside the cards. Tap another card to move on. To build a selection of several, long-press a card (or ⌘-tap with a mouse), and ⇧-tap picks a range. The toolbar then shows how many are selected, with None and Delete. Right-click a card to delete it.

Deleting a fixture asks first, and cannot be undone. Every delete on this page — the toolbar's Delete N, the right-click menu, the fixture editor's Delete button and the same menu on the Fixtures panel — puts up one question that names what is about to go (“Delete fixture 12 (Mac Aura, U3/A1)?”). Answer it and the fixture leaves the patch here, on Babel and on every Light in the session; the console saves the show two seconds later. Undo does not bring a fixture back and no backup is taken, so the question is the last stop. Presets, groups and cues keep their references to the number, so re-patching it restores those links. Nothing on the keyboard completes the delete — the confirm button has no shortcut, and Esc cancels.

Selecting several fixtures gives you the multi-editor: sequential numbering, sequential addressing, sequential IP and sequential naming across the selection. Sequential numbering is all-or-nothing — one clash and nothing moves — and it rewrites every preset, cue, group and pad binding that pointed at the old numbers.

Finding a profile

profile find generic rgbwauv   search the fixture library
profile import <libraryID>     adopt it so patch will accept it
profile list                    what this console has
profile reset <id> | all        undo local edits, back to the shipped profile

profile find returns the twelve best matches with the exact profile import line to run. Import is safe to repeat, echoes the channel map it adopted, and gives you the patch line to use. profile list sorts what you have into three groups — built-ins you have edited, profiles you imported from the library, and profiles authored from the rig itself — because each one has a different way out. profile reset only makes sense for the first group, and says so for the others.

Devices

A device is patched exactly like a lamp — a profile, a fixture number, and a host. From then on it is selected and driven like anything else, and the console sends nothing device-specific itself: it publishes values, and Babel speaks the device's own protocol.

DeviceHow you drive it
ATEM switcherspgm 4 and pvw 4 set the buses; pgm + and pgm - step through them. cut, auto (or take) and ftb do the transitions. The generated ATEM PGM / PVW / Trans / Keys pools give you the same thing as tiles; a tbar fader is the lever and atemtrans is the rate. Program and preview keys light from the switcher's own tally. A gamepad reaches the switcher too — see the law below.
VISCA PTZ camerasPan, tilt, zoom and focus are ordinary attributes, so pan 60 works and so does a gamepad. home recentres, af is a one-push autofocus, camstart save and camstart recall store and recall a camera's whole pose.
Panasonic camerasPatched and driven as attributes, with a hundred recallable presets. Five models ship, and they are not interchangeable — the AW-UE40 takes a reduced command set, so it has its own profile. Pick the right model.
Panasonic projectorsPower, shutter, blank, freeze, input, light output, test pattern and lens shift / focus / zoom / memory, in the displays domain.
Monitorsddc luminance 80 and the rest of the DDC set — contrast, volume, mute, input, red, green, blue.

Displays and wall processors

Projectors, LED walls and wall processors live in the Displays domain. The shipped library includes only personalities backed by a complete manufacturer chart: current Panasonic Art-Net projector modes, Barco Pulse DMX modes, Christie 24-channel Art-Net modes, Brompton Tessera factory personalities and the fully documented NovaStar fixed Art-Net layout. A model with no published DMX chart is not represented by a guessed personality.

The Patch editor's Display Control block stores the receiver setup beside the fixture: protocol and personality, host and port, Art-Net Net / Sub-Net / Universe or sACN universe, and the fixture's normal DMX start address. PJLink and Vendor are available as honest control-path labels for devices that do not expose a DMX personality; they do not invent DMX channels. Tap Protocol and the choices pop out as a list, the same way every other picker in Patch behaves — in the add sheet and in the editor alike. Changing it moves the port to that protocol's default unless you have typed one of your own.

Display passwords stay on this Mac

A per-fixture web/admin user may travel with the patch, but its password is stored in the macOS login Keychain under the fixture's stable identity. Show save and export omit the password bytes. Moving a show to another console therefore requires entering that display password on the destination Mac.

A pad binding drives whatever the attribute belongs to

Bind any control on a gamepad — a stick, the HOTAS throttle or twist, a trigger — to an ATEM channel such as T-Bar or PVW Source, and it drives the patched switcher, not the camera the pad's cursor happens to be sitting on. The attribute decides, not which piece of plastic you bound it to. Bind that same control to Pan, Tilt or Zoom and it drives the cursor camera exactly as before, group and all.

One thing to know before you bind a spring-return stick to the T-bar: a stick offers Absolute only, and absolute means the control is the value — let go of a sprung stick and it re-centres, so the T-bar parks mid-throw and holds the switcher mid-transition. The HOTAS throttle stays where you leave it, which is why it is the lever that suits a T-bar. Use the throttle, or a tbar fader tile, for a throw you have to complete.

Two ATEM profiles, and they are not interchangeable

ATEM SDI Extreme ISO has eight inputs. ATEM Constellation HD 1ME has ten, four upstream keys, one downstream key and six aux outputs — and its source values sit at different numbers, which is exactly why it is a separate profile rather than a revision. pgm 9 works on a Constellation and is refused on an Extreme. Because the two disagree, Command and Babel must be deployed together.

home, af and camstart are VISCA-only

They will not reach a Panasonic camera, even though it has both a home and a one-push autofocus channel — you will get “no camera patched”. Drive those from the camera's own attributes for now.

The device verbs — cut, auto, ftb, pvw, pgm, home, af, camstart — take an optional fixture number; without one they find the first patched device of that kind. The stepping forms (pgm +, pvw -) always use the first patched ATEM.

Camera positions you record land in the generated Camera Pos pool, so a camera move is a preset like any other.

There is also a wall verb for LED walls — wall @404/1 10x6 176x176 2.84 patches a processor with its cabinet grid, cabinet size in pixels and pitch, and wall <n> fill h|v|hv|1to1 sets how the paired output fills it.

Outputs

output 1 exclusive on            give an output sole use
output 1 ndi 1920 1080          NDI size for an output
output 1 shader warp on         warp / edge-blend / curve / lens
output 1 refresh 60             refresh rate
canvas 3840 2160                the output canvas size

Warp / Blend is the editor for the same thing, per output. The canvas size lives on the outputs: canvas 3840 2160 (or the canvas control in the window) stamps every patched Phantos Output with it and tells Light, and the window lays the outputs out on it the moment it is known. With no output patched there is no canvas, and the window says so. A Phantos Master is optional — patch one for a master fader, a test pattern, borders, or a cue-recordable canvas preset; you never need one to get a canvas. Pick an output from the strip along the top; it joins the canvas, where every selected output is drawn at its true place and size on the canvas with its own live picture inside. Add more outputs with Stitch to see several at once — where two touch is the join, where they overlap is the blend zone, tinted orange. Drag the four corner handles on any output's tile to warp that output — they grab where you put your finger and move from there, so a grab is never a jump, and it takes a real drag: a tap on a handle does nothing. Grabbing a handle on another output makes it the one you are editing. Pinch (or scroll a mouse wheel) to zoom the canvas and drag empty canvas to pan; Fit zooms to the selected outputs' extents, All shows the whole canvas again. With no canvas size known the same handles sit on a single-output plate with the live picture behind them. The stepper column beside the canvas is the same four corners as numbers, and it is the value to trust when you need one. Every control here writes a fixture channel, so a warp records into a preset or a cue and fades like any other attribute.

Warp Mode sits in the column above the corner numbers: 4-Point is a corner pin — straight edges stay straight, the four handles are the whole warp; 8-Point is Light's bilinear warp, which also carries Curvature. It is a fixture channel like everything else here, so it records and fades. With several outputs stitched the row shows the mode they share, or MIXED when they differ — tap a mode to set all of them at once.

8-Point brings its own controls up. Switch to it and the four edge midpoint handles — TM, ML, MR, BM — appear on every tile and on the corner-pin plate, with their own rows in the numbers fold. 4-Point shows the four corners only, and that is not an omission: 4-Point is a corner pin, and the midpoints genuinely do nothing in it.

CENTER, the row under Warp Mode, adds a ninth handle in the middle of the frame. In 8-Point it is the warp's centre point. In 4-Point it pinches or bulges the middle while the corner pin is held — drag it and the four corners and all four edges stay exactly where you put them. Off is the default, and with it off the picture is exactly what it was. Like the mode, it addresses every stitched output and shows MIXED when they differ.

All nine points are fixture channels, so a warp — corners, midpoints, centre and the centre's on/off — records into a preset or a cue and fades like any other attribute. Reset flattens all nine and switches the centre off. Lens correction is the one thing still not built here. Curvature, Scale and Rotation are.

Auto Blend and warping are independent. Auto Blend owns the four edge-blend widths and nothing else — you can seam-detect an output and still warp its corners.
