11Command line reference

Every verb the command line accepts. Type it in the command line at the bottom of the screen, or on the Command Keypad tile, and press Return. Tab completes the first word. This list is generated from the console’s own verb catalog, so it cannot drift from what the console will actually run.

Selection shorthand

A bare number is a selection — no verb needed.

<n> [thru <m>] [+ <n>…] [@ <0-100|full>]

1 thru 5 @ 50 · 2 + 4 + 6 @ full

merge
merge <object> — exec <n> cue <m> [refs] folds the programmer INTO that cue keeping what it already holds (bare = baked values; `refs` also folds in live preset refs — the cue editor's "Add live programmer look"); group <n> ADDS the current selection to its members; preset <n[.sub]> merges the programmer in (same funnel as `update preset`)
e.g. merge group 2
recall
recall <object> — object = preset <n[.sub]> | group <n> | exec <n> (the object standalone recalls too)
e.g. recall preset 3
recordstore, s
record <object> — object = preset|group|exec; addressed group|exec <n> lands at THAT slot (occupied refuses — use update/merge); `record exec <n> cue [<m>]` ADDS a cue to an existing executor (the non-destructive path the occupied refusal points at); preset [<n[.sub]>] [<type>|all] either order: the slot's pool names its type (5.1 = gobo), a type word (colour/color·intensity·position·gobo·beam·effects·shaper·video·time·…·all, letters ok) records typed next-free, both must agree; bare `record preset` opens the type menu
e.g. record group 2
updateu
update <object> [cue <m>] — exec <n> cue <m> folds the programmer into that cue; preset <n[.sub]> merges; group <n> ← current selection
e.g. update executor 1 cue 2
